# Паспорт данных лабораторной №3

Источник: [Construction Site Safety v28](https://universe.roboflow.com/roboflow-universe-projects/construction-site-safety/dataset/28), Roboflow Universe Projects. Зеркало: [snehilsanyal / Kaggle](https://www.kaggle.com/datasets/snehilsanyal/construction-site-safety-image-dataset-roboflow). Дата получения: 2026-11-18. Лицензия набора по документации источника: CC BY 4.0; атрибуция и ссылки на составные источники сохранены в README.dataset.txt. Индивидуальные права на составные фотографии не проверены; некоторые содержат водяные знаки. Исходные фотографии повторно в Git не публикуются.

Архив: 2801 изображение, экспорт v28 от 2023-02-01. Его SHA256 и хэш манифеста записаны в provenance.json. Содержимое архива получается программой scripts/download_data.py. Набор лабораторной: 194 уникальных исходных имени из исходных valid/test (готовые offline-аугментации train исключены); прежнее разбиение полностью отброшено. Выбор упрощает обучение на CPU и исключает раздувание выборки пятью производными версиями. Пригодность источника для реальной промышленной эксплуатации не установлена.

Новое разбиение: train 135 / validation 31 / test 28. Группы видео, одинаковые имена, SHA256 и perceptual hash объединены до разбиения. Все generic youtube-* объединены консервативно в одну группу, construction-* — в другую. Дополнительные объединения по визуальному осмотру всех 194 кадров перечислены в scene-overrides.json. Реальные ID камер неизвестны: используются явно описанные прокси-группы, остаточный риск схожих сцен сохраняется. Поиск группового разбиения seed=42 использует только размеры групп и классы, не предсказания модели. Манифест заморожен до обучения.

Воспроизведение: scripts/prepare_data.py восстанавливает точные файлы по манифесту. Создание нового разбиения требует сознательно убрать манифест; это другой эксперимент, его метрики нельзя смешивать с текущими.

## Схема и правила

YOLO TXT: одна рамка на строку `class_id x_center y_center width height`. Координаты нормированы на ширину/высоту. Все изображения исходником растянуты до 640×640; геометрические пропорции могут быть искажены.

| Поле | Тип / единицы | Роль | Пропуски / диапазон / проверка |
|---|---|---|---|
|image|Путь к JPEG|Вход модели|Обязателен; читаемость и SHA256|
|class_id|Целое 0–9|Целевая метка|Обязательно для каждой рамки; словарь ниже|
|x_center,y_center|Вещественные, доля размера|Целевая геометрия|Конечные, [0,1]|
|width,height|Вещественные, доля размера|Целевая геометрия|Конечные, (0,1]|
|original|Строка исходного имени|Трассировка|Из имени до .rf.; не вход модели|
|group|Строка, прокси источника|Группирующий признак|Не пересекается между split; не вход модели|
|split|train/val/test|Служебное поле|Фиксируется манифестом|
|sha256,label_sha256|Hex SHA256|Версионирование|Проверяются для каждого файла|

Классы: 0 Hardhat, 1 Mask, 2 NO-Hardhat, 3 NO-Mask, 4 NO-Safety Vest, 5 Person, 6 Safety Cone, 7 Safety Vest, 8 machinery, 9 vehicle.

Отрицательные классы **имеют собственные рамки**: NO-Hardhat — область головы без каски; NO-Mask — область лица без маски; NO-Safety Vest — видимая область торса без сигнального жилета. Это не отсутствие положительного детекта и не логическое отрицание всего изображения. Person, голова/каска и торс могут перекрываться как разные объекты. Нельзя считать отсутствие найденной каски доказательством нарушения. Для отвернувшихся, перекрытых и далёких людей отрицательные классы неоднозначны.

Сохраняются правила источника: в оценке не смешиваются переклассифицированные рамки. Граница machinery/vehicle местами спорна (самосвалы размечены machinery). Рамки обрезанных объектов ограничены видимой/оценённой областью по исходной разметке; последовательность проверена выборочно. Пустой TXT допустим для фонового кадра. Спорные рамки записаны в reports/annotation-audit.md, автоматических исправлений нет.

## Ограничения

Смешаны стройки, автодромы, магазины, домашние селфи с масками и постановочные/рекламные фото. География, демографический состав, камеры и согласия участников не документированы подробно; репрезентативность не гарантирована. Есть пережатие, пересветка, тёмные кадры, водяные знаки, титры, отражения, малые и перекрытые объекты. В тесте machinery и vehicle имеют по одному объекту, поэтому AP этих классов крайне нестабилен. Валидация содержит 58 machinery, но только 3 Hardhat и 1 Safety Cone: средняя метрика чувствительна к составу источников.

Для человеческой проверки подготовлены 40 кадров (reports/audit-selection.json); агент их визуально просмотрел. Требование ручной проверки студентом остаётся отдельным пунктом до подтверждения.
