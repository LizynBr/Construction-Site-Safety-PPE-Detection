# Проверка кода и исправления

Проверку выполнил Codex; это самопроверка, не независимое человеческое рецензирование.

1. Источник содержал абсолютные пути Kaggle и относительные пути вне data. Добавлены переносимые configs/ppe.yaml, манифест и проверка существования/целостности всех файлов; проверено validate-data и реальным обучением.
2. Готовые offline-аугментации могли пересекать сцены. Исключён исходный train, исходные valid/test заново объединены по именам, SHA256, pHash и визуальным прокси-группам. Проверки утечки намеренно получают пересекающиеся группы/хэши/имена и должны падать.
3. Прямое применение к JFIF не поддерживается текущим загрузчиком Ultralytics. Изображения декодируются Pillow, передаются как RGB. Исходный запуск подтвердил обработку пяти файлов.
4. DetMetrics установленной версии не имеет save_dir. Путь отчёта фиксируется через абсолютный project/name; предсуществующий каталог запрещён. Исправление проверено отдельным E1 validation запуском api-smoke, получен metrics.json. Test не использовался для этой отладки.
5. Повторные предсказания одного GT не должны увеличивать TP. Тест проверяет один TP и один FP при двух одинаковых предсказаниях. Отдельно проверено несовпадение класса.
6. E1/E2 могут случайно отличаться многими параметрами. Тест сравнивает конфигурации после исключения имени запуска и единственного фактора freeze.
7. Загруженный архив проверяется SHA256 и на выход путей за пределы каталога распаковки. Секрет GitHub используется только в памяти процесса обращения к API и не сохраняется в репозитории.

Ограничение трассировки E1: исходники были ещё не закоммичены в момент начала запуска; соответствие конфигурации и позднейшего коммита описано в experiment-plan.md. Ручная проверка студентом, независимое рецензирование PR и устная защита остаются действиями людей.
